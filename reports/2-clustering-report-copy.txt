LAPORAN HASIL CLUSTERING

1. Data Preprocessing
Sebelum dilakukan clustering, dataset dilakukan preprocessing untuk memastikan kualitas data.

Tahapan preprocessing:
    a. Handling Missing Value
        Missing value diperiksa karena algoritma clustering menggunakan perhitungan jarak antar data. Nilai kosong dapat menyebabkan hasil clustering menjadi kurang akurat.
        Nilai kosong pada fitur numerik ditangani menggunakan median, sedangkan fitur kategorikal menggunakan modus.
    b. Data Cleaning
        Data duplikat dihapus agar tidak menyebabkan bias pada proses pembentukan cluster.
    c. Feature Selection
        Clustering menggunakan fitur numerik karena algoritma clustering bekerja berdasarkan perhitungan jarak antar data.

2. Standardisasi Data
StandardScaler digunakan untuk menyamakan skala antar fitur.

Tujuannya:
    - Menghindari fitur dengan nilai besar mendominasi proses clustering.
    - Membuat perhitungan jarak antar data menjadi lebih seimbang.

3. Reduksi Dimensi Menggunakan PCA
PCA (Principal Component Analysis) digunakan untuk mengurangi jumlah dimensi data.

Tujuan PCA:
    - Mengurangi kompleksitas data.
    - Mempertahankan informasi utama.
    - Mempercepat proses clustering.

Dimensi data direduksi menjadi kurang dari 10 komponen sebelum proses clustering.

4. Penentuan Jumlah Cluster
Hierarchical Clustering digunakan pada sample data sebanyak 15.000 data untuk melihat struktur awal cluster.
Jumlah cluster diuji dari K = 2 sampai K = 10 menggunakan Silhouette Score.

Silhouette Score digunakan untuk mengukur:
    - Kemiripan data dalam cluster yang sama.
    - Perbedaan antar cluster.

Hasil pengujian menunjukkan jumlah cluster terbaik: K = 2

5. Hasil K-Means Clustering
Setelah mendapatkan jumlah cluster terbaik, K-Means diterapkan untuk menghasilkan segmentasi akhir.

Hasil:
Cluster 0 : 3.703 data
Cluster 1 : 11.297 data


6. Evaluasi Clustering
Silhouette Score: 0.2579
Interpretasi:
Nilai silhouette mendekati 1 menunjukkan cluster semakin terpisah dengan baik, sedangkan nilai mendekati 0 menunjukkan adanya overlap antar cluster.
Nilai 0.2579 menunjukkan bahwa model berhasil menemukan pola kelompok dalam data, tetapi masih terdapat beberapa data dengan karakteristik yang mirip antar cluster.

7. Analisis Karakteristik Cluster

Cluster 0:
Jumlah data: 3.703
Karakteristik:
- Memiliki rata-rata loan amount lebih tinggi.
- Rata-rata loan amount sekitar 386571.
- Merupakan kelompok dengan karakteristik pinjaman bernilai lebih besar.
Interpretasi:
Cluster 0 dapat dianggap sebagai kelompok pengguna dengan kebutuhan pembiayaan yang lebih tinggi.

Cluster 1:
Jumlah data: 11.297
Karakteristik:
- Merupakan cluster terbesar.
- Memiliki rata-rata loan amount sekitar 275488.
- Memiliki pola data yang lebih umum.
Interpretasi:
Cluster 1 merupakan kelompok mayoritas dengan karakteristik pinjaman yang lebih rendah dibandingkan Cluster 0.


8. Kesimpulan
Metode kombinasi Hierarchical Clustering dan K-Means berhasil melakukan segmentasi dataset menjadi dua kelompok utama.
Hierarchical Clustering digunakan untuk menentukan jumlah cluster optimal berdasarkan Silhouette Score, kemudian K-Means digunakan untuk melakukan clustering akhir karena lebih efisien pada dataset yang besar.

Hasil akhir menunjukkan:
- Cluster 0: kelompok dengan nilai pinjaman lebih besar.
- Cluster 1: kelompok mayoritas dengan nilai pinjaman lebih rendah.

Dengan Silhouette Score sebesar 0.2579, clustering menunjukkan adanya struktur kelompok pada data meskipun masih terdapat sedikit kemiripan antar cluster.
